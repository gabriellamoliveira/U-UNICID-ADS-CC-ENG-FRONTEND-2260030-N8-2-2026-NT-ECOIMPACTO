# EcoFuture 🌱

Um site educativo sobre sustentabilidade, impacto social e acessibilidade, com identidade visual verde, cartões interativos por CSS e layout responsivo.

## Publicar com GitHub Pages

1. Crie um repositório no GitHub chamado `ecofuture`.
2. Extraia este ZIP e envie **todos os arquivos** para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)` e clique em **Save**.
6. Quando o GitHub Pages concluir a publicação, use o endereço apresentado em Settings → Pages. Normalmente será `https://SEU-USUARIO.github.io/ecofuture/`.

## Páginas incluídas

- `index.html` — Início
- `conceitos.html` — Conceitos
- `objetivos.html` — Objetivos globais
- `consumo.html` — Consumo consciente
- `reciclagem.html` — Resíduos e reciclagem
- `agua.html` — Água
- `energia.html` — Energia e clima
- `impacto-social.html` — Impacto social
- `acessibilidade.html` — Acessibilidade
- `participe.html` — Participe

## Recursos

- HTML5 e CSS3, sem JavaScript e sem dependências externas.
- Layout adaptável para celulares, tablets e computadores.
- Link para pular ao conteúdo, regiões semânticas, foco visível e navegação por teclado.
- Controles CSS para alto contraste e ampliação do texto.
- Animações leves com respeito a `prefers-reduced-motion`.
- `.nojekyll` para publicação estática simples no GitHub Pages.

## Acessibilidade

A implementação inclui boas práticas, mas isso não garante conformidade integral com WCAG. Recomenda-se validar com ferramentas automáticas, navegação somente por teclado, leitores de tela e testes com pessoas com deficiência.
