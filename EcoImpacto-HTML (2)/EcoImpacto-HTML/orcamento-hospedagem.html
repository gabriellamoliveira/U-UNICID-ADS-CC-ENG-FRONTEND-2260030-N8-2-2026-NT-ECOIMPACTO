Escolha recomendada e justificativa

Recomendamos GitHub Pages com o domínio ecoimpacto.com.br, com custo total estimado de ≈ R$ 40 por ano. O site é composto apenas por arquivos estáticos (HTML, CSS e JavaScript), então uma hospedagem gratuita com HTTPS atende bem. A integração com o Git já usado pela equipe simplifica as atualizações, e o domínio .com.br transmite confiança ao público brasileiro. Hospedagem estática também consome menos recursos de servidor — coerente com a proposta de reduzir desperdícios digitais.
