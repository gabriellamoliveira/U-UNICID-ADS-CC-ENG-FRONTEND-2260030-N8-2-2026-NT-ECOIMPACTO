Proposta de acompanhamento

  1. 1Coleta periódica

    Registro mensal dos dados de cada iniciativa em planilhas simples e abertas.

  2. 2Transparência

    Publicação dos indicadores no site, com identificação clara das fontes.

  3. 3Revisão comunitária

    Encontros trimestrais com a comunidade para avaliar resultados e prioridades.

  4. 4Melhoria contínua

    Ajuste das metas e das ações a partir do que os dados mostrarem.
