# EcoFuture 🌱

Site educativo sobre sustentabilidade, impacto social e acessibilidade. Projeto estático construído com **HTML5, CSS3 e JavaScript**, sem dependências externas.

## Páginas
1. `index.html` — Início
2. `conceitos.html` — Conceitos de sustentabilidade
3. `objetivos.html` — Objetivos globais/ODS
4. `consumo.html` — Consumo consciente
5. `reciclagem.html` — Resíduos e reciclagem
6. `agua.html` — Água
7. `energia.html` — Energia e clima
8. `impacto-social.html` — Impacto social
9. `participe.html` — Participação e compromisso
10. `acessibilidade.html` — Acessibilidade

## Recursos implementados
- Navegação consistente e link para pular ao conteúdo principal.
- Layout responsivo com CSS Grid/Flexbox.
- Preferências de alto contraste e texto ampliado salvas no navegador.
- Checklist de compromissos com persistência local.
- Formulário demonstrativo com validação e armazenamento local.
- Respeito à preferência `prefers-reduced-motion`.
- Sem bibliotecas ou requisições externas.

## Limites e transparência
- O formulário de participação é demonstrativo: os dados ficam somente no navegador local e **não são enviados** à organização.
- Não há banco de dados, envio de e-mail, processamento de doações ou integração real com IA.
- Os recursos são boas práticas iniciais, não uma certificação de conformidade WCAG. Faça testes manuais e com leitores de tela.

## Publicação no GitHub Pages
1. Envie o conteúdo desta pasta para a raiz do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Selecione **Deploy from a branch**, branch `main` e pasta `/(root)`.
4. Salve e aguarde a publicação.
5. Abra o endereço exibido em Settings → Pages e teste todas as páginas em HTTPS.
