# Plano de testes — EcoFuture

## Testes funcionais
- [ ] Abrir cada página pelo menu e confirmar que não há links quebrados.
- [ ] Ativar alto contraste e navegar para outra página; verificar persistência.
- [ ] Ativar texto ampliado e verificar legibilidade.
- [ ] Marcar compromissos em `participe.html`, atualizar a página e verificar persistência.
- [ ] Enviar o formulário vazio e confirmar a validação nativa.
- [ ] Enviar o formulário preenchido e confirmar a mensagem de que o registro é local.
- [ ] Verificar que nenhuma mensagem afirma que a equipe recebeu a inscrição.

## Testes responsivos
- [ ] 360 px (celular pequeno)
- [ ] 768 px (tablet)
- [ ] 1366 px (desktop)
- [ ] Zoom do navegador em 200%

## Testes de acessibilidade
- [ ] Navegar por todo o site somente com Tab, Shift+Tab, Enter e Espaço.
- [ ] Confirmar foco visível em links, botões, inputs e selects.
- [ ] Conferir ordem de títulos e nomes acessíveis.
- [ ] Conferir contraste de texto e componentes.
- [ ] Testar com leitor de tela.
- [ ] Testar preferência de movimento reduzido do sistema.
- [ ] Validar HTML e CSS com validadores apropriados.

Anote navegador, sistema, data, resultado e evidência de cada teste.
