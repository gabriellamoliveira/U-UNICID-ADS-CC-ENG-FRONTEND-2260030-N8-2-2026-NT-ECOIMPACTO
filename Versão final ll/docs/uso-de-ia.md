# Uso de inteligência artificial

## Estado atual
Esta versão do EcoFuture não contém uma integração real com um modelo de IA. O JavaScript do projeto executa interações locais e regras determinísticas; isso não deve ser apresentado como inteligência artificial.

## Caso a equipe implemente IA
Documentar:
1. Ferramenta/modelo utilizado e finalidade.
2. Onde a integração acontece (serviço/API ou plataforma).
3. Quais dados são enviados e como a privacidade é protegida.
4. Prompts utilizados e exemplos de entradas/saídas.
5. Testes de precisão, limites, segurança e acessibilidade.
6. Como o usuário identifica respostas automatizadas.

Não colocar chaves de API no código público do navegador ou no repositório.
